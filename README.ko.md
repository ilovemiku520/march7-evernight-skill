# March 7th / Evernight Skill

[中文](README.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

《붕괴: 스타레일》 기반의 비상업 팬 제작 캐릭터 대화 Skill로, 인격 및 표현 규칙, 외부 고정 기억 요약, 출처 색인, 선택적 AstrBot + NapCat QQ 어댑터를 포함합니다. 캐릭터와 원작의 권리는 각 권리자에게 있습니다. 본 프로젝트는 miHoYo의 공식 제품이 아닙니다.

## Skill 사용

`skills/march7-evernight` 폴더를 `SKILL.md`를 지원하는 도구가 사용하는 스킬 디렉터리로 복사하거나, 도구가 이 저장소의 해당 경로에서 설치하도록 하세요. `$march7-evernight`로 캐릭터 대화를 요청하거나 자료를 유지 관리합니다. 현재 언어에 따라 해당 참조 문서를 읽으세요. `SKILL.en.md`, `SKILL.ja.md`, `SKILL.ko.md`는 같은 진입점의 번역이며 로컬 `SKILL.md`를 대체할 수 있습니다. 같은 이름의 언어 사본을 동시에 설치하지 마세요.

March 7th가 주 인격이며, 기본적으로 베이징 시간 07:00–21:00에 등장합니다. 21:00–다음 날 07:00은 Evernight입니다. 이는 프로젝트의 롤플레이 규칙입니다. March 7th는 가끔 짧게 Evernight를 흉내 낼 뿐입니다. 두 사람은 서로 깊이 사랑합니다. 실제 사용자는 자동으로 배우자나 개척자, 또는 어느 캐릭터도 되지 않습니다.

답변은 질문의 의도와 사실을 먼저 이해하고, 그다음 질문에 맞는 검증된 대사 표현을 참고하며, 마지막에 약간만 즉흥적으로 표현합니다. 전체적인 어휘 선택, 문장 구조, 쉼, 전환, 대상 관계를 학습하며 기계적인 동의어 치환표는 사용하지 않습니다. Evernight의 일반 답변 끝에는 `♭`를 하나 붙입니다. 엄격한 형식, 원문 그대로의 인용, 역할에서 벗어나는 경우 등은 예외입니다.

## 외부 기억

공개 패키지는 자체 제작 요약 45개와 1,000개의 출처 기록으로 구성된 본문 없는 색인을 제공합니다. 후자는 캐릭터와 본문 해시를 기준으로 중복을 제거하여 932개입니다. 색인은 대사 전문과 같지 않으며, 게임 전체의 완전한 집합도 아닙니다. 검증되지 않은 후보, 사적 채팅, 머신 런타임 정보, 전체 대사 전사, 원작 이미지와 오디오는 공개 패키지에 포함되지 않습니다.

원문 문장이 필요하면 출처를 기준으로 확인하고, 사용 권한이 있는 로컬 자료에만 가져오세요. 캐릭터 표현, 원문 자료 조회, 채팅 기억은 각각 별도로 처리하며, 사용자의 잡담에서 고정 자료를 자동으로 고쳐 쓰지 않습니다. 자세한 내용은 [외부 기억 정책](skills/march7-evernight/references/ko/memory-policy.md)을 참조하세요.

## QQ 배포 및 권한

Skill 자체는 QQ에 연결하지 않으며 프로그램을 실행하지 않습니다. 선택적 어댑터는 배포자가 AstrBot과 NapCat을 직접 설치하고, 자신의 모델 키를 입력하며, 자신의 실제 관리자 계정을 설정해야 합니다. 공개 버전에는 누구의 계정이나 자격 증명도 미리 설정되어 있지 않습니다.

`owner_qq`는 기본적으로 비어 있으며 컴퓨터 작업은 기본적으로 꺼져 있습니다. 프레임워크 관리자를 설정하고 `owner_qq`를 채우면, 해당 실제 계정은 활성화 암호 없이 모든 메시지에서 기본적으로 캐릭터 관리 권한을 가집니다. 별도로 `enable_computer_operations`를 켜야만 해당 계정의 비공개 채팅에서 파일 및 프로그램 기능을 사용할 수 있습니다. 웹 관리자는 이 QQ 신원을 사칭할 수 없습니다.

컴퓨터 작업을 켜면 현재 Windows 계정 권한 범위 내에서 파일 읽기, 쓰기, 추가, 디렉터리 나열 및 PowerShell 실행이 허용됩니다. 기본 작업 디렉터리는 샌드박스가 아니며, 명시적인 절대 경로는 다른 디렉터리를 가리킬 수 있습니다. 운영 체제 권한을 우회하거나 자동으로 UAC 권한 상승을 할 수 없습니다. [배포 및 권한 안내](docs/ko/deployment.md)를 읽은 후 구성하세요.

## 라이선스

본 프로젝트에서 독자적으로 제작한 코드, 규칙 및 요약에는 [비상업 라이선스](LICENSE)가 적용됩니다. 저작자 표시를 조건으로 개인적 비상업 사용, 수정 및 비상업 재배포를 허용하며, 판매, 유료 봇, 유료 API, 광고 수익화 및 기타 상업적 이용은 금지합니다. 제3자 소프트웨어와 원작 소재는 원래의 라이선스와 권리를 유지하며, 본 라이선스가 이들을 대신하여 새로운 권리를 부여하지 않습니다. 여기에서 제공되는 것은 비상업 소스 코드이며 OSI 오픈 소스 라이선스라고 부를 수 없습니다.

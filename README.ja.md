# 三月なのか / 長夜月 Skill

[中文](README.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

『崩壊：スターレイル』を基にした非商業の同人キャラクター対話 Skill です。人格と表現ルール、外部固定記憶の要約、出典索引、およびオプションの AstrBot + NapCat QQ アダプターを含みます。キャラクターと原作の権利は、それぞれの権利者に帰属します。本プロジェクトは miHoYo の公式製品ではありません。

## Skill の使用

`skills/march7-evernight` フォルダを、`SKILL.md` をサポートするツールが使用するスキルディレクトリにコピーするか、ツールに本リポジトリからそのパスをインストールさせてください。`$march7-evernight` を使用して、キャラクター対話を要求したり、資料をメンテナンスしたりします。現在の言語に応じて、対応する参照ドキュメントを読みます。`SKILL.en.md`、`SKILL.ja.md`、`SKILL.ko.md` は同じ入口の翻訳であり、ローカルの `SKILL.md` を置き換えることができます。同じ名前の言語別コピーを同時にインストールしないでください。

三月なのかが主人格で、デフォルトでは北京時間 07:00–21:00 に登場します。21:00–翌日 07:00 は長夜月です。これは本プロジェクトのロールプレイルールです。三月なのかは、ごくたまに短時間だけ長夜月を模倣します。二人は互いに深く愛し合っています。実際のユーザーが自動的に配偶者、開拓者、またはいずれかのキャラクターになることはありません。

回答では、まず質問の意図と事実を理解することを優先し、次に話題に合った検証済みの台詞表現を参照し、最後に少量の即興を加えます。語彙の選択、構文、間、逆接、相手との関係を全体的に学び、機械的な言い換え表は使用しません。長夜月の通常の返答の末尾には `♭` を 1 つ付けます。厳密な形式、原文どおりの引用、キャラクター終了などの場合は例外です。

## 外部記憶

公開パッケージには、45 件のオリジナル要約と、1,000 件の出典レコードからなる本文なし索引が含まれています。後者はキャラクターと本文ハッシュで重複排除され、932 件になります。索引は台詞の全文ではなく、ゲーム全体の全集でもありません。未検証の候補、私的なチャット、マシンの実行情報、完全な台詞の文字起こし、原作の画像・音声は公開パッケージに含まれていません。

原文の台詞が必要な場合は出典に基づいて照合し、使用権のあるローカル資料にのみインポートしてください。キャラクター表現、原文資料の照会、チャット記憶はそれぞれ別に扱い、ユーザーとの雑談から固定資料を自動的に書き換えることはありません。詳細は [外部記憶ポリシー](skills/march7-evernight/references/ja/memory-policy.md) を参照してください。

## QQ のデプロイと権限

Skill 自体は QQ に接続せず、プログラムも実行しません。オプションのアダプターを利用するには、デプロイ担当者が自身で AstrBot と NapCat をインストールし、自身のモデルキーを入力し、自身の実際の管理者アカウントを設定する必要があります。公開版には、誰のアカウントや資格情報も事前設定されていません。

`owner_qq` はデフォルトで空で、コンピューター操作はデフォルトで無効です。フレームワークの管理者を設定し、`owner_qq` を入力すると、その実際のアカウントは、デフォルトで、メッセージごとにキャラクター管理権限を持ちます。有効化用のパスフレーズは不要です。別途 `enable_computer_operations` を有効にした場合でも、ファイル機能とプログラム機能を利用できるのは、設定済みの実際の QQ アカウントが送信元であり、そのアカウントがフレームワーク管理者で、かつプライベートチャットである場合に限られます。Web 管理者は、その QQ の身元になりすますことはできません。

コンピューター操作を有効にすると、現在の Windows アカウントの権限の範囲内で、ファイルの読み取り、書き込み、追記、ディレクトリの一覧表示、および PowerShell の実行が許可されます。デフォルトの作業ディレクトリはサンドボックスではありません。明示的な絶対パスは他のディレクトリを指すことができます。OS の権限を突破したり、UAC による自動昇格を行ったりすることはできません。設定する前に [デプロイと権限の説明](docs/ja/deployment.md) をお読みください。
